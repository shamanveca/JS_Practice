# JS_Practice_somethinggram

<h1 align="center"> Самостоятельный проект "Какой-то-грам". Площадка для фотографий </h1>

 ### Мной написан только JS код
HTML и CSS писал **НЕ Я !!!** 

**В данной работе реализовано:**
- Изоляция кода с помощью IIFE и разделение блоков по отдельным файлам
- Прописана небольшая часть работы с backend`ом, а именно: отправка формы на сервер, запрос данных с сервера и работа с ними, обработка ошибок и обработка статусов ответа сервера
- Рендер фотографий на главной странице по описанному шаблону в `template` (Прописан рендеринг как из папки, так и из данных полученных с сервера)
- Загрузка изображения и отображение его в окне превью с помощью работы с **base-64**
- Применение разных фильтров (яркость, контрастность и т.п.) к изображению на этапе превью
- Изменение насыженности фильтров с помощью ползунка (**Drag'n'Drop**)
- Сортировка изображений на главной странице (радномное отображение фотографий(алгоритм Фишера-Йетса), по убыванию комментариев, случайные 10 фото из массива и главная страница(попорядку))
- Открытие popup'а по нажатию на изображение. Показывает полноразмерное изображение, также в этот момент подтягиваются комментарии к данной фотографии, описание от человека загрузившего фото и аватарки всех этих пользователей
