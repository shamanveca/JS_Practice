# JS_Practice_JS_animation

<h1 align="center"> Анимация дождя </h1>

### Описание:
2D Анимация дождя на чистом JS с использованием Canvas. В данном прокте практиковалось:
- Отрисовка графики на Canvas и работы с ней
- Создание конструкторов
- Использование контекста с помощью `this`
- Наследование с использованием метода `prototype` у конструкторов
- Обращение (вызов) к конструкторам и методом через `call` и зоздание полиморфных методов
